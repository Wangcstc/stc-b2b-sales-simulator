# 安装说明（Windows / Mac / Linux）

> 这份写给**第一次装、不熟悉命令行**的人：在自己电脑上把系统跑起来，用样品题试玩。
> 要部署成团队在线用的网站，装好后再看同目录的《部署说明》。
>
> Windows 10/11、macOS、Linux 都支持，每次发版都在这三种系统上自动装一遍、跑一遍测试（GitHub 上的 CI 检查）。

---

## 一、先装三样东西

| 要装的 | 去哪下 | 说明 |
|---|---|---|
| **Node.js 20 或更高**（选 LTS 版） | https://nodejs.org | 一路下一步。装完重开一次命令行窗口 |
| **Git** | Windows：https://git-scm.com/download/win　Mac：第一次在终端敲 `git` 会提示安装 | 用来下载代码。不想装也行：在 GitHub 页面点 Code → Download ZIP，解压即可 |
| **数据库 PostgreSQL 16**（二选一，见第三步） | — | 系统的账号、对局、评分都存在这里 |

还需要一个 **DeepSeek API 密钥**（https://platform.deepseek.com 注册申请，`sk-` 开头）。AI 客户回话、打分都靠它，费用从你自己的账户扣。

**命令在哪里敲：**

- Windows：开始菜单搜「PowerShell」打开。
- Mac：启动台里打开「终端」。

下面所有命令，三个系统都一样，复制粘贴回车即可。

## 二、下载代码、装依赖

```bash
git clone https://github.com/Wangcstc/stc-b2b-sales-simulator.git
cd stc-b2b-sales-simulator
npm install
npm run setup
```

`npm run setup` 会生成配置文件 `.env`，并自动填好登录用的密钥。**它会提示你还要手工填 DeepSeek 密钥**：

- Windows：`notepad .env`
- Mac：`open -e .env`

找到 `DEEPSEEK_API_KEY=` 那一行，把 `sk-xxxx…` 换成你自己的密钥，保存。

> 文件夹路径里有中文、有空格都没关系。

## 三、准备数据库（二选一）

### 办法 A：Docker（推荐，命令最少）

1. 装 Docker Desktop：https://www.docker.com/products/docker-desktop （Windows 安装时按提示开启 WSL 2，装完重启一次电脑）。
2. 打开 Docker Desktop，等左下角显示正在运行。
3. 在项目目录里：

   ```bash
   npm run db:up
   ```

`.env` 里的数据库地址已经配好了，不用改。

### 办法 B：直接装 PostgreSQL（不想装 Docker）

1. 下载安装 PostgreSQL 16：
   - Windows：https://www.postgresql.org/download/windows/ （EDB 安装包）。安装时设一个管理员密码并记住，端口保持 5432，其余一路下一步。
   - Mac：装 Postgres.app（https://postgresapp.com），打开后点 Initialize。
2. 打开数据库命令行：
   - Windows：开始菜单里的「SQL Shell (psql)」，一路回车，最后输入刚才设的密码。
   - Mac：Postgres.app 里双击 postgres 数据库。

   然后粘贴这两行：

   ```sql
   CREATE USER drill WITH PASSWORD 'drill_local_dev';
   CREATE DATABASE drill OWNER drill;
   ```

3. 改 `.env` 里的数据库地址：办法 B 的端口是 **5432**（Docker 那条路是 5433）：

   ```
   DATABASE_URL="postgresql://drill:drill_local_dev@localhost:5432/drill?schema=public"
   ```

## 四、建表、建主管账号、装样品题，启动

```bash
npx prisma migrate deploy
npm run seed
npm run bank -- load samples/bank
npm run dev
```

看到 `Ready` 后，浏览器打开 **http://localhost:3100**。

- 用简码 **`ADMIN`** 登录。**第一次登录时输入的口令就是以后的口令**（至少 6 位，不能是纯数字）。
- 样品题库有 8 道虚构的露营用品询盘，可以直接开练。
- 想做自己公司的题库：登录后点顶部「题库工坊」，投你们自己的聊天记录。

**以后每次使用**：打开命令行，进项目目录（`cd stc-b2b-sales-simulator`），用办法 A 的先打开 Docker Desktop，再 `npm run dev`。

**让同事也能用**：`npm run build` 之后用 `npm run start` 启动，同事在浏览器打开 `http://<你这台电脑的内网 IP>:3100`。Windows 第一次会弹防火墙提示，点「允许」。

## 五、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `npm` 或 `node` 不是内部或外部命令 | Node.js 没装好，或装完没重开窗口 | 重开 PowerShell / 终端；还不行就重装 Node.js |
| PowerShell 提示「禁止运行脚本」 | Windows 默认不让运行 npm 的 .ps1 脚本 | 运行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按 Y 确认 |
| `Can't reach database server` | 数据库没启动，或 `.env` 里端口不对 | 办法 A：打开 Docker Desktop 再 `npm run db:up`；办法 B：端口要写 5432 |
| `npm run db:up` 报 docker 找不到 | Docker Desktop 没装或没打开 | 打开 Docker Desktop，等它显示运行中再试 |
| 端口 3100 已被占用 | 已经开着一个，或别的程序占了 | 关掉之前的命令行窗口；或直接用浏览器打开 http://localhost:3100 |
| 登录后一开局就报错 | 数据库表没建 | 再跑一次 `npx prisma migrate deploy` |
| AI 客户不回话、报告出不来 | DeepSeek 密钥没填或余额不足 | 检查 `.env` 里的 `DEEPSEEK_API_KEY`，到 DeepSeek 后台看余额 |
| 首页显示「还没有题库」 | 样品题没装 | `npm run bank -- load samples/bank` |
| 改了 `.env` 不生效 | 改完要重启 | 在运行 `npm run dev` 的窗口按 Ctrl+C，再运行一次 |
