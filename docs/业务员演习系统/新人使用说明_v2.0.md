# 新人第一次使用说明 v2.0

> 给第一次打开这套系统的业务员。
> **第 1 章看完就去练第一局**，剩下的边练边查。全文当手册用，不用背。

**v2.1 改了什么**（2026-08-24，按系统 v4.0 对齐规则）：

- 首页改成**系统派单**：不再自己从三档里挑，每天派三封；想挑考点去「全部询盘」；
- 红线**三条改四条**，加了 **R4 用中文作答**；红线不再需要主管复核；
- 通过标准**四条改一条**：最近 2 个业务日 6 局的**局分中位数 ≥ 65**；
- 新增**正式业务员的周考**（每周至少 2 场）；
- 界面：TAB 变成四个，深浅色切换已取消。

**v2.0 改了什么**（用过 v1.0 的看这里，没用过跳过）：

- 补上 v1.0 漏掉的三件要命的事：**客户全程说英文**、**第一句该发什么**、**什么时候该结束这一局**；
- 修正 v1.0 一处误导：考试"不可中途退出重来"**不是**指不能关浏览器（详见第 9 章）；
- 新增：一轮怎么算、20 轮怎么分配、翻译的三条脾气、暗牌是什么、术语表、出错自查表、桌面速查卡。

## 一、五分钟上手

急着开练的话，只需要知道这 8 件事：

| # | 这件事 | 一句话 |
|---|---|---|
| 1 | 这是什么 | 假客户，真陪练。练砸了不影响你任何考核 |
| 2 | 怎么登录 | 填简码 → 第一次自己设口令 |
| 3 | 练哪个 | 首页「今日待接待」有系统派给你的三封（简单/标准/困难各一），挑一封点「接待」 |
| 4 | **客户说英文** | 全程英文。你可以打中文，按 **Ctrl+K** 译成英文再发 |
| 5 | **一轮怎么算** | 你发一句（或提交一次报价）＝ 1 轮，**上限 20 轮**。报价也占一轮 |
| 6 | **每轮说什么** | 回答他一个问题，**顺手抛一个问题出去**。别回完就等着 |
| 7 | 目标是什么 | 把右边**六要素**问齐（产品属性/数量/定制/地址条款/到货时间/其他），**数量没确认死也不能报价** |
| 8 | 怎么收尾 | 点「结束并复盘」→ **答完 5 个问题**才有报告 |

**看完这张表就可以去打第一局了。** 卡住了再回来查下面的章节。

## 二、先说清楚这是什么

**这是一套陪你练接询盘的系统。客户是假的，你说的话是真的。**

它干三件事：

1. 给你一封真实感的询盘，你像接真客户一样跟"客户"聊；
2. 聊完先问你 5 个问题，你答完它才给诊断——**不答不给分**；
3. 出一份报告：哪一轮说错了、当时该怎么说、**这个客户心里真正在想什么**。

**两件它不干的事，现在就记住：**

- 演习分叫**演习段位 D**（D1–D5），和公司正式的业务员等级**不是一个池子**，不用于晋升、淘汰、排名。练砸了不影响你什么。
- 通过考试后系统只说一句话：**「已获得询盘接待准入资格」**。就是允许你接真询盘了，不代表你达到了哪个等级。

所以：**放开手练，故意试错才划算。** 真客户被你聊死了就是没了，这里聊死了看报告就行。

## 四、第一次登录（一分钟）

1. 打开网址 → 自动跳到登录页；
2. **第一步只填简码** → 「下一步」；
3. **第二步设口令**：至少 6 位、别用纯数字，输两遍 → 「设好口令并进入」。

以后用这个简码 + 口令登录，**30 天内不用重登**。

省得你疑惑的三件事：

- 填了简码点下一步，系统**不会告诉你这个简码存不存在**，一律进第二步。这是防外人拿这页试出公司有谁，不是卡住了。
- 「简码或口令不对」＝这两样有一样不对，重来。
- **忘了口令找主管重置**，重置后下次登录再设一个新的。

## 六、打完第一局

### 6.1 选一封询盘

首页「今日待接待」**每天派三封**：简单、标准、困难各一。三档考的东西不一样：

| 档 | 这一档考什么 |
|---|---|
| 🟢 **简单** | 先把话听清楚——客户说的和你以为的，是不是同一件事 |
| 🟡 **标准** | 推进卡在哪里——沉默、决策链、复购、临门让步 |
| 🔴 **困难** | 要判断的东西不在字面上——风险、边界、价格锚点、真实身份 |

**怎么操作**：卡片上点「看询盘原文」展开看内容 → 点 **「接待」** 开局。
练完一封会自动补一封新的上来；今天这三封不想练，点「换一批」（每天一次）。

**想练指定考点**：点最下面的 **「全部询盘」** → 上面一排先选考点（或按难度、局型、练没练过筛）
→ 点那一行的「接待」；不想挑就点「随机来一封」。那边全池开放，不受这三封限制。

> **点接待之前先看一眼数据。** 「买家等级 / 近 90 天登录 / 浏览次数 / 有效询盘 / 标签 / 被拉黑 ⚑」不是装饰，是要考你的。
> 有的客户询盘只有一句废话，但登录了 71 天、浏览了 1259 次——只看询盘你会当垃圾客户扔掉，看行为数据才知道是十年老买家。
>
> 行里两个记号要认：**「探需局／跟进局」**（跟进局摆的是前情，不是客户刚说的话）、**◈**（这个客户有背调资料包可查）。

### 6.2 对话页长什么样

**左边**是聊天区，最上面那条是客户的询盘原文，顶上写着 `第 X / 20 轮`。

**右边侧栏**从上到下：

1. **客户信息**——姓名、国家、公司、买家等级、平台行为数据；
2. **产品参数表**——属性、FOB 深圳阶梯价、加价项、**报价格式规则**（报价前必看）；
3. **六要素清单**——你的仪表盘，见 6.6；
4. 触发红线会多出一张红卡；报过价会多出报价记录；
5. 最底下「显示状态板」——**跑局时别看**。那是客户的耐心/信任/兴趣数值，看了你就不是在读人，是在刷数值了。

### 6.3 ★ 客户全程说英文 ★

**这一条 v1.0 漏了，很多人第一次进去就卡在这。**

- 客户从询盘到每一轮回复，**全部是英文**。你跟他说中文，他会回一句 "sorry, I don't speak Chinese"，然后照样说英文；
- **你可以打中文**——输入框中英文都收，按 **Ctrl+K** 译成商务英语再发；
- **系统没有英译中按钮**。看不懂客户说什么，用浏览器自带的网页翻译（右键 →「翻译成中文」），或复制出去翻。

> 英语不好不丢人，也不扣分——**七力里没有"英语水平"这一项**。真实的阿里后台本来就带一键翻译，业务员天天在用。
> 这套系统考的是你**问什么、按什么顺序问、有没有问到六要素**。别把脑力耗在憋英文句子上。

### 6.4 ★ 第一句发什么 ★

新人卡最久的就是这一句。给你一个能直接用的框架：

**第一条消息 = 打个招呼 + 回应他问的那件事 + 抛出你的第一个问题**，三样合在一条里发出去。

三样各自的意思：

| 成分 | 干什么 | 反面教材 |
|---|---|---|
| 打招呼 | 叫出他的名字，一句就够 | 整段 "Dear Sir or Madam" 客套 |
| 回应他问的 | 他问什么你先答什么，**别答非所问** | 上来就背公司介绍，他问的那句当没看见 |
| 抛第一个问题 | 把主动权拿回来 | 回完就等着——进程立刻停摆 |

**第一个问题问什么？** 从六要素里挑他**最没交代清楚**的那一项。多数探需局是「数量」或「产品属性」。

> **这里有个演习和真实平台的差异，你要知道：**
> 真实平台上王老师教的是「**先占坑**」——不知道回什么就先发一句招呼把 5 分钟极速回复指标锁死，再慢慢研究客户。
> 但**演习里不计时，轮次却只有 20 轮**。所以别把一整轮浪费在一句 "Hi Tom" 上——**在这里要把占坑那一句和第一个问题合并成一条发出去**。
> 这个差异只影响"发几条"，不影响那个习惯：真实平台上，看到信息就回，没有任何理由。

### 6.5 每一轮的动作：回答一个，抛一个

**这是全系统最值钱的一条规矩，来自第一课的控场心法：**

> **回完客户的问题就不能停，必须再抛一个问题出去。**

不这么做的后果：回完就等 → 进程停摆 → 客户消失了你还在猜为什么。而且系统会记：**连续 3 轮没问出新信息，客户直接 ghost，判负。**

两个能立刻用上的技法：

- **给选择题，不给填空题**：别问 "你需要什么容量？"，问 "我们有 3.6L 和 6L 两个规格，你要哪个？"——降低客户的决策成本；
- **问信息时包一层利他外壳**：别问 "让我知道一下你有没有货代"，问 "你在中国有货代吗？**需要我帮你找一个吗？**"——同一个目的，客户的感受从"他在套我信息"变成"这人眼里有我"。

客户不回你的问题？**不纠缠，继续抛新问题往前推。**

### 6.6 六要素：这一局的及格线

右边这六项就是接询盘必须问清楚的：

**产品属性 · 数量 · 定制需求 · 收货地址/条款 · 到货时间 · 其他需求**

| 标记 | 含义 |
|---|---|
| ✓ 绿色 | 你**问出来**的，算你的功劳 |
| △ 黄色 | **客户主动给**的，**不算你的功劳** |
| □ 灰色 | 还没有 |

**报告里会白纸黑字写「六要素·你问出来的 3/6」。** 所以别等客户自己说。

**怎样才算"你问出来的"？**
系统读的是**你实际发出去的那条英文**。所以：

- 想到了但没发出去 → 不算；
- 问得太含糊，抽取不出来 → 可能不打勾。**问具体一点**；
- **翻译不会替你多问**（见 6.7），别指望它帮你补。

**踩到底的标准**（这几条最容易丢分）：

- **产品属性**要踩到底：款式、颜色、尺寸、参数、配件、插头标准（美标/欧标）。停在"他要露营椅"这一层不算问到；
- **数量必须分属性确认**："3 个颜色要 1000 个"——是每色 1000 共 3000，还是合计 1000？合计的话每色各多少？
- **地址和到货时间一起问**。到货时间一箭三雕：定物流方案、倒推付款截止日、判断这单还在不在；
- **其他需求**是报价前的兜底："对这个采购订单你还有没有其他特别要求？"

> 考试模式下这张清单会**隐藏**——不然考的是抄清单，不是你会不会。所以练手时就得把它背进脑子。

### 6.7 翻译：知道它的三条脾气

按 **Ctrl+K** 把输入框里的中文译成商务英语（本来就是英文的话就帮你润色）。

**译完不会自动发**，结果放回输入框让你过一眼，不对可以点「撤销」退回中文。**这一眼是这个功能一半的价值**，别省。

三条脾气，不知道会以为它坏了：

| 脾气 | 说明 |
|---|---|
| **不增不减** | 你只写"你要多少？"，译文就只有这一句，**不会好心帮你补问交期、用途**。多译一句＝系统判你问过了＝六要素凭空多一个勾，所以它被明令禁止 |
| **不加问候语** | 除非你自己写了，否则译文**不会有 Hi / Best regards / 署名**。这是聊天窗不是邮件——不是漏了 |
| **太短会报错** | 出现「这句太短或太口语，没能译好」，把话说完整一点再试。它宁可报错，也不把中文原样吐回来让你误发出去 |

### 6.8 报价：走「报价」按钮，别在聊天框里报

输入框上方那排小按钮，第一个是 **「报价」**。

填单价、数量、运费，勾选有没有生成报价表、有没有附截图。面板底下实时算总额、档位、格式合不合规：

| 总额 | 档位 | 格式要求 |
|---|---|---|
| < USD 100 | A | 纯文字就行 |
| USD 100–300 | B | **至少要截图** |
| > USD 300 | C | **报价表 + 截图** |

**为什么不能在聊天里报**：报价是要判分的动作——金额分档、格式合规、报的数量跟客户真实数量对不对得上，走表单才判得准。

**⚠️ 两件事：**

- **数量没确认就发报价 = 触发红线①**，纯代码判定，没得解释；
- **提交一次报价 = 消耗一轮。** 20 轮预算里要留出这一轮。

### 6.9 背调：只有带 ◈ 的局有

按钮条上的 **「背调」**（没这个按钮说明本局没资料包）。

**故意设计成两步：**

1. 点「发起背调」，一键出 AI 报告；
2. **再一项一项点开**「查官网」「查社媒」「比对联系方式」，自己交叉验证。

**只看 AI 报告、一项都不点开，等于没做背调，系统会记下来。** AI 会张冠李戴，对不上的地方才是线索。**查出来一片空白也是结论**——有的客户就是什么都查不到，那恰恰是最强的一条证据。

发现矛盾之后**不要裸问身份**。按这个顺序来：

> 先垫一句认可 → 摆出矛盾点 → 问真实用途 → 接一个利他出口。

直接拿背调结论去质问，客户会懵，信任直接掉。

另外：**只对核心客户（≥300 美金）做深度背调。** 为个小单耗一堆轮次，客户耐心照样掉，不加分。

### 6.10 ★ 什么时候点「结束并复盘」★

**这一条 v1.0 漏了。** 太早结束和拖到 20 轮，都会让你白打一局。

**满足下面任意一条就可以收了：**

- 六要素**你问出来的 ≥ 4 项**，该报价的也报了；
- 客户已经明确表态（下单意向 / 明确拒绝 / 给了明确的下一步）；
- 剩不到 3 轮了。

**别做这两件事：**

| 别这样 | 为什么 |
|---|---|
| 聊两三轮就结束 | 证据太少，报告会写「**本局证据不足以给出精确局分**」，不给分。你白打了 |
| 一直拖到 20 轮 | 判定是「超轮数，客户已选其他供应商」，等于输了 |

**中途想走随时能走**——点左上角「← 返回」。局存在库里，首页顶上会出现一颗「继续未聊完的局」，回来接着打，**不会丢**。

### 6.11 一轮怎么算，20 轮怎么花

**你发一句话 = 1 轮。提交一次报价 = 1 轮。** 客户的回复不额外占轮。

一个够用的预算（探需局参考）：

| 阶段 | 轮次 | 干什么 |
|---|---|---|
| 开场 | 第 1 轮 | 招呼 + 回应 + 第一个问题（合并成一条） |
| 探需 | 第 2–12 轮 | 六要素逐个踩到底，每轮**回一个抛一个** |
| 背调 | 穿插 | 只对 ≥300 美金的客户做 |
| 报价 | 第 13–16 轮 | 数量确认死了才报，注意格式档位 |
| 收尾 | 第 17–19 轮 | 确认下一步，然后自己点「结束并复盘」 |

**局是怎么结束的：**

| 结局 | 触发条件 |
|---|---|
| **客户 ghost（判负）** | 客户耐心归零，或**连续 3 轮你没问出任何新信息** |
| **超轮数** | 打满 20 轮，客户已选其他供应商 |
| **正常结束** | 你自己点「结束并复盘」 |

> "ghost" ＝ 客户从此不读不回、人间蒸发。真实平台上这是最常见的死法，所以系统把它做成了判负。

## 七、复盘问答：这套系统的灵魂

聊完点 **「结束并复盘」**，注意——**它不会直接给分**，先问你 5 个问题。

- **一次只显示一题**，答完才出下一题（防止你扫一眼挑简单的答）；
- 前 3 题**针对你这一局**（"第 3 轮你为什么…"），后 2 题固定；
- 左边摆着这一局的完整记录，**照着记录答，别凭印象编**；
- 答得太虚会**追问一次**，就一次，说真话就行；
- 可以点「跳过复盘直接看报告」，报告会盖一句「因未作答，以下判断为系统推断」。**建议别跳**；
- ★ 2026-08-28 起**考试局也能跳过** ★ 复盘作答质量本来就不计分，
  再把它卡在评分前面，就成了「必须做、但做不做不改变任何结果」——那种事最后一定被敷衍。

> 为什么还是建议你答：
> **你讲不出来，就说明你觉得用不上；用不上就产生不了效果。**
> 复盘不计分，留着它是因为想清楚当时为什么那么问，比看一份报告有用得多。

5 问答完 → 「生成报告」，等约 1 分钟。

## 八、报告怎么读

七节，按这个顺序看最省时间：

| 节 | 内容 | 怎么用 |
|---|---|---|
| 一、你的答案盘点 | 你刚才那 5 个回答 | 扫过 |
| 二、本局结论 | 段位 + 局分 + 结局 + 红旗 | 看一眼就走，**别在这纠结** |
| 三、客观事实表 | 六要素问出来几个、红线、暗牌 | **硬伤在这，认真看** |
| 四、七力评分与证据链 | 七维打分 + 原话证据 + 下一步 | 只看被扣分的那两项 |
| 五、逐段点评 | 逐轮：你说了啥 → 问题 → **王老师会怎么说** → 当时该怎么说（中英对照） | **全文最值钱，逐条读** |
| 六、掀开客户暗牌 | 客户心里真正在想什么、你第几轮错过了它 | 真人带教给不了你的东西 |
| 七、这一局只练一个动作 | 一句话 | **抄下来，下一局就练它** |

**演习段位对照：**

| 原始局分 | 段位 |
|---|---|
| 0–24 | D1 起步期 |
| 25–49 | D2 成长期 |
| 50–64 | D3 熟练期 |
| 65–79 | D4 进阶期 |
| 80–100 | D5 专家期 |

**七力**：洞察力、引导力、方案力、信任力、闭环力、博弈力、稳定力。

**看到这两句别慌：**

- 「**本局证据不足以给出精确局分**」——不是系统坏了。局太短、证据太少时它**故意不给分**：样本不足给一个精确到个位的分数，比不给分更有害，因为它看起来很客观。下一局多聊几轮再结束；
- 某一项写「**证据不足，不计入分母**」——这一维度本局没考到，不扣你分。

## 九、四条红线

| 红线 | 定义 |
|---|---|
| **① 数量未知即报价** | 数量还没确认就点了发送报价。纯代码判定，**无解释空间** |
| **② 疑罪从有** | 客户出现可疑特征后，你明显降低接待投入（回复变短、停止提问、主动收尾）。由模型判定 |
| **③ 空催** | 跟进时既没新信息、又没由头、也没价值点的纯催促——"你看到报价了吗""在吗"。**每次跟进必须有由头 + 带价值** |
| **④ 用中文作答** | 把中文直接发给客户。纯代码判定（查有没有汉字）。**先按 Ctrl+K 译成英文再发** |

红线①为什么这么狠：不同数量对应不同价格档、不同装箱方案。不知道数量就报价，要么你在给同行送价格，要么客户拿你的价去比价。

红线②的另一面是第一课的铁律**疑罪从无**：客户可疑，你可以多查、可以设边界，但**不能因为怀疑就降低服务质量**。

> **红线不直接判你过不过**（2026-08-21 起）：它照常检测、照常写进报告，
> 但会扣客户的信任、耐心和兴趣，客户提前走人，**局分自然就低了**。别把"不判"当成"没事"。

## 十、考试闸门

**先练手，不着急考。** 练手局不限次数、不计入准入。

### 10.1 开考前

先点「考前必读」整页读完，再回来点「开考」——**开考要二次确认**，因为一天只有一次。

### 10.2 「不可中途退出重来」到底是什么意思

**v1.0 这句话写得会吓到人，这里说清楚：**

| 可以 | 不可以 |
|---|---|
| ✅ 打完第 1 局，关掉浏览器，吃完饭回来接着打第 2 局 | ❌ 觉得第 1 局打砸了，想重开一场考试 |
| ✅ 三局分开打，中间去干别的 | ❌ 同一天考第二次 |
| ✅ 中途「← 返回」，回考试闸门页再进去 | ❌ 换一个人设重抽 |

**开考的一瞬间，3 局就全部生成好了**，躺在考试闸门页等你，一局一局点进去打。关浏览器不会丢。

**但是——当天开考就当天打完。** 考试记录按"人 + 日期"记，跨到第二天那场就悬在那儿结算不了了。

### 10.3 考试局在哪进入

**不在首页「模拟询盘」里**（那是练手池）。走 **🎯 考试闸门** 页，每一局后面有「开始这一局 / 继续 / 去评分 / 看报告」的链接。

### 10.4 规则

- 每人**每日 1 场**；
- 3 局：探需局 ×2（一标准一困难）+ 跟进局 ×1，每局最多 20 轮；
- 人设从**考试专用池**抽，**都是你没见过的**。开考后如果看到绿字「本次使用考试专用题：这 3 个客户在模拟询盘里见不到」，说明抽题正常；
- 考试中**六要素清单隐藏**，侧栏只留产品参数和报价格式规则；
- 复盘**建议答，但可以跳过**（2026-08-28 起，与练手局一致）；
- 每局打完都要「结束并复盘」出分。**3 局都出分，系统自动交卷**，不用你去点。
- **实习业务员要先解锁**：当天先练够 3 局有效演习，且三局**不能全是简单**。
  正式业务员不要求，随时可考。
  ★ 2026-08-28 起「一局算不算数」换了第三条 ★ 要**聊满 6 轮 + 出了报告 + 这一局真问出了东西**
  （至少解开一张暗牌，或至少开口问过一项六要素）。第三条原来是「做完复盘」，
  复盘改成可选之后换掉了——**寒暄、自我介绍、发目录都不算问**。
  明明练过进度却没涨，多半是有一局光聊没问。

### 10.5 通过标准只有一条（实习业务员）

**最近 2 个业务日、每天 3 局、共 6 局的局分中位数 ≥ 65。** 就这一条。

- **判的不是今天这一场**——一天发挥失常拉不垮，连着 2 天不达标才会动你的资格；
- **缺考算不达标，而且补不回来**：那天没考，那 3 格就空着，今天多打几局也填不进去；
- 洞察力、复盘作答质量、红线**照常评、照常写进报告，但不参与判定**；
- 考了但系统没评出分（证据不足）→ **不算你的**，不记不达标。

**判过了会怎样**：次日获得新询盘分配权，进入在岗期。
**连着 2 天不达标**：次日起暂停给你分新询盘，退回训练期——**只停"分新的"，手上的客户不动**。

每晚**凌晨 00:05** 结算、次一个业务日生效。今天考到哪一步、差多少分，在「考试闸门」页看。

**当天没打完的考试，就在这一趟结算里作废**（2026-08-28 起）：第二天它点不动了，
不计考试次数；已经打完并出分的局照常计入判定窗口，没打完的那几局补不回来。
第二天要考，得回「考试闸门」重新开一场。

### 10.6 正式业务员：周考

- **每周至少 2 场**（合计 6 局出分），周一到周日算一周，每天最多 1 场；
- **不要求先练够几局**，随时可考；
- 中位数旁边那条 65 分是**参考线，不是门槛**；
- **只记录，不影响任何权限**：不影响询盘分配，也不动你的正式等级。

**通过了也只是入场券**：样本远低于正式定级门槛。上岗后前 20 个真实询盘仍要逐个复盘，真实局分才是最终验证。

## 十一、出问题了怎么办

| 现象 | 原因 | 你该做什么 |
|---|---|---|
| 网页打不开 / ERR_CONNECTION_REFUSED | 服务没启动 | 找主管，不是你的问题 |
| 「简码或口令不对」 | 两样有一样错了 | 重填。忘了口令找主管重置 |
| 客户说的话看不懂 | 客户全程英文，系统没有英译中 | 浏览器右键「翻译成中文」 |
| 点 Ctrl+K 报「这句太短或太口语」 | 太短的句子译不好 | 把话说完整再译。**别把中文直接发出去** |
| 译文里没有 Hi / Best regards | **故意的**，聊天窗不是邮件 | 不用管。真要问候语，自己在中文里写 |
| 六要素问了却没打勾 | 问得太含糊，或者根本没发出去 | 问具体一点，重新问一次 |
| 「这局刚才在另一个窗口继续到第 X 轮」 | 你开了两个窗口/两台电脑打同一局 | 最新对话已同步好，你那句还在输入框里——**看完客户的新回复再决定发不发**，别原样重发 |
| 生成报告失败 / 提示未配置 API KEY | 后台模型密钥没配 | 找主管。局不会丢，配好了回来重点「生成报告」 |
| 报告说「证据不足以给出精确局分」 | 这局太短 | 不是故障。下一局多聊几轮再结束 |
| 找不到我的考试局 | 考试局不在「模拟询盘」里 | 去「考试闸门」页，每局后面有链接 |
| 考试状态一直是「进行中」 | 还有局没出分 | 页面上写着还差几局，去打完并复盘出分；3 局都出分会自动交卷 |
| 考试按钮是灰的 | 今天这场考完了，或演习局还没练够 | 按钮下面那句话写着差什么，照着补 |

**其他几个常被问到的：**

- **能看别人的局吗？** 不能。首页「最近的局」只有你自己的。主管能看全员，但只能看，不能替你聊。
- **分数会影响转正/绩效吗？** 不会。演习段位 D 和正式等级物理隔离，不进正式定级样本池。
- **「台账导出」下载的是什么？** 一份 Excel，你自己的全部演习记录（局型、难度、七力分、六要素、红线）。主管点是全员的。

## 十二、术语表

| 词 | 意思 |
|---|---|
| **探需局** | 新询盘进来，从零开始摸需求。大部分局都是这种 |
| **跟进局** | 之前聊过、断了，这一局是接着跟。**页面最上面那段是"前情"，不是客户刚说的话** |
| **人设 / 变体** | 客户的性格与底牌设定。同一个人设有多个变体，考试用的是你没见过的那批 |
| **暗牌** | 客户心里藏着、嘴上不说的东西（真实用途、真实预算、真实身份、决策链）。**问对了才会解锁**，报告第六节会全部掀开给你看 |
| **干扰项** | 客户在特定轮次抛出来打乱你节奏的话（"先给个价""要实物视频"）。报告里显示「简单 + 干扰项」就是这种局。**别被带走，答完继续推你的六要素** |
| **六要素** | 产品属性 / 数量 / 定制需求 / 收货地址条款 / 到货时间 / 其他需求 |
| **七力** | 洞察力、引导力、方案力、信任力、闭环力、博弈力、稳定力 |
| **演习段位 D** | 本系统的分档 D1–D5，**和公司正式等级不是一个池子** |
| **演习 ID** | 每局的编号，形如 `D-简码-...`，带你的简码。`D-` 前缀表示这是演习数据 |
| **ghost** | 客户从此不读不回、人间蒸发。系统里判负 |

## 十三、头三天怎么练

| 第几天 | 做什么 |
|---|---|
| **第 1 天** | 就打首页派的那三封，**再去「全部询盘」按难度筛「简单」多打几封**。每局都认真答复盘 5 问；报告只读第五节「逐段点评」和第七节「只练一个动作」 |
| **第 2 天** | 首页三封照打。**开局前先把上一份报告的「只练一个动作」抄在纸上，这一局只练它** |
| **第 3 天** | 去「全部询盘」筛「困难」挑 2 局，**带 ◈ 的一定要打**（练背调）。回头对比：六要素"你问出来"的数字涨了没有 |

**练到什么程度可以去考试：**
简单和标准档能稳定收齐 **5–6 个六要素**、连续三局**不触红线**、报告里**洞察力稳定 ≥3 分**。
